## 年份在前的日期兼容修复

真实任务暴露了 `YYYY/M/D` 日期无法绘制折线的问题：工具原先只识别 ISO 日期，后续错误被预算耗尽提示掩盖。现支持未补零的年份在前日期并按日历顺序排序，绘图 CSV 保留原始标签；无效日期、混合日/月歧义和等价重复日期仍明确拒绝。失败记录保留首次绘图错误及调用 ID，主图不强制重复失败委派。

完整离线回归 **466 项测试、28 项子用例通过**，新增跨月/跨年排序、斜杠及连字符日期、真实双 Agent 流程和错误诊断检查。相同真实 CSV 与原任务在线重跑完成，主模型 4 次、子模型 3 次；折线数据逐项匹配独立全量汇总，最高/最低日期及差值正确，源哈希不变，实际 PNG 标签和坐标轴正常。个人 CSV、数值结果、日志和图片未发布。

## 在线与 VS Code 验收

使用已有本地模型配置，在包内对话入口分别验证三种图型。

1. 问卷按部门求非空满意度均值，画柱状图；手算运营 13/3、教务 11/3、研发 3。
2. 使用公开合成月份数据，打乱行顺序后绘制折线；核对实际时间排序及对应数值。
3. 完整数值列绘制直方图；按记录边界手算每箱频数、有效数、缺失数。
4. 追问修改图型或标题，再修改 Top K /筛选范围；前者复用授权统计，后者重新计算。
5. 提供资料并要求依据说明；核对真实检索与来源。只要表格任务核对零委派。
6. 需要口径时真实提问，回答后完成绘图；核对恢复预算和执行次数。

记录主/子模型调用数、耗时、工具执行、图片及源哈希。分别登记离线、在线和远程 CI 的实际结果，未运行的检查保持未验证。
