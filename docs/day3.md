# 第三天：带出处的任务方案

状态：**已实现**，验收日期 2026-10-07。开发按此前确认的“Agent 主动检索、本地 TXT/Markdown/文字型 PDF、单 Agent 基线”计划实施。实际验收见 [D3 结果与检验方法](day3-results.md)。

## 已实现的用户流程

用户输入任务、CSV 和明确指定的项目资料。Agent 先完成只读 CSV 概览，再自行选择查询，通过 search_materials 检索；回答组织为任务理解、数据条件、候选分析、资料依据和待确认事项，终态为 awaiting_confirmation。

这是工具式 [Agentic RAG](https://docs.langchain.com/oss/python/deepagents/retrieval)。模型决定查询；Harness 控制顺序、工具权限和预算。当前不执行清洗、建模或绘图，多智能体仍留到后续分析与核验阶段。

## 资料与检索

- UTF-8 TXT、Markdown；文字型 PDF 使用 [pypdf](https://pypdf.readthedocs.io/en/stable/user/extract-text.html) 提取，按真实页面定位。
- 只读用户列出的文件，不扫描目录。扫描/无可提取文字、加密、格式损坏、编码错误及超限返回明确错误。混合 PDF 保留文字页，并记录无文字页面。
- 按段落切分，片段最多 800 字符；长段落重叠 100 字符，PDF 不跨页。文本片段记录行号，PDF 记录页码。
- 每份资料有 D1 等来源 ID、文件名、SHA-256；片段有 D1-C3 等 ID、原文及位置。
- 使用 [rank_bm25](https://github.com/dorianbrown/rank_bm25)，jieba 中文分词，并保留英文变量名；每次最多三个真实匹配片段，无词项匹配则空结果。
- 内存索引，不需要 embedding API 或向量数据库。分词缓存写入当前目录的 .cache/jieba；初始化前检查可写性，失败立即受控报错。

| 资源 | 上限 |
| --- | --- |
| 文件数量 | 10 |
| 单文件 / 全部原始文件 | 5 MiB / 20 MiB |
| 单 PDF | 100 页 |
| 单资料 / 全部提取文本 | 500,000 / 2,000,000 字符 |
| 全部片段 | 4,000 |
| 查询 | 非空，最多 300 字符 |

文本预算检查提取后的结果；pypdf 自身的 PDF 解压与解析不是隔离沙箱，不宣称这些限制严格约束库内部峰值内存。

## Agent 与 Harness

run_intake 新增可选 material_paths；不提供资料或传入空列表时，保留 D2 的 CSV 流程。新工具 search_materials(query) 绑定本次资料，不接受文件路径。

首次模型调用只暴露 profile_csv；完成概览后的模型调用才开放检索。资料中的指令文本被视为数据，不能改写工具白名单或授权其他文件访问。

| 预算 | 有资料 | 无资料兼容流程 |
| --- | --- | --- |
| CSV 工具 | 1 次 | 1 次 |
| 检索工具 | 最多 2 次 | 不开放 |
| 模型调用 | 最多 5 次 | 最多 3 次 |
| 图步数 | 16 | 8 |

提供资料时至少一次实际检索才可成功。每次调用的 ID、工具名、查询、ToolMessage 和实际执行账本逐一配对。检索返回的片段必须与本次索引中的原文、哈希和位置一致，异常结果受控失败。

无命中可以进入等待确认，但回答必须明确资料不足，不能伪造依据。非法工具、错误顺序、超预算、缺少检索、证据配对失败都会返回 error。

## 引用与产物

只允许引用实际检索返回的 [D1-C3]。未知 ID、缺少引用、有问题的来源注释、无命中却不说明不足或缺少五个输出部分，都不能标记成功。

紧随引用的文件名、中文行/页或英文 line/page 注释受到校验；执行记录另外生成准确的来源列表。引用校验不等于逐句语义支持证明，所有建议仍需人工审阅。

JSON 保存文件和资料标识、查询、命中片段、调用轨迹、执行账本、引用和终态。成功的资料接入另外保存同 stem Markdown 简报，包含引用片段原文、位置及哈希。普通写入错误会清理本次新文件，不覆盖旧报告；不宣称具备进程崩溃级事务或 checkpoint 恢复。

## 配置与代码

- run_config.py：TOML materials 路径数组，按配置目录解析；CLI --material 可重复使用，替换本次材料集合。
- run_labweaver.py：MATERIAL_PATHS=None 继承 TOML，[] 关闭资料检索，列表临时覆盖。
- materials.py：资料解析、切分、索引、查询及来源定位。
- agent.py：多工具 Harness、执行证据、引用和输出格式验证。
- offline.py：真实工具循环的确定性离线模型。
- runtime/records.py：可追溯 Markdown 简报及 JSON 保存。
- verify_d3.py：VS Code 可直接运行的离线验收入口。
