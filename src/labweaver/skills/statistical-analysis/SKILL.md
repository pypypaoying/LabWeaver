# 统计分析

先把问题落实为数据范围、分组粒度、指标公式、排序字段与缺失口径。使用用户明确给出的定义；未指定且影响很小时说明合理默认值，只有会实质改变结果的歧义才澄清。基于已冻结 TaskSpec 计算，不能为使检查通过而换目标或删要求。

## 汇总与分布

- 行数、非空值计数、去重实体数是不同指标；选用符合记录粒度的口径，并命名清楚。分组为空是否单独保留也要与任务一致。
- 比率通常按 `sum(分子) / sum(分母)` 计算。合并预聚合均值时按各组有效样本数加权；除非任务明确要求“各组等权”，不要直接平均组均值。加权均值为 `sum(值 * 权重) / sum(权重)`；权重为零、负数或缺失时先依据语义处理。
- 算术均值、几何均值和中位数不可互换。正数的几何均值可用 `exp(mean(log(x)))`；遇到零或负数时说明定义域，按明确规则处理，不能偷偷改为绝对值、丢行或替换为普通均值。含零的非负样本按通常乘积定义可得到零，但对数实现需要单独分支。
- 偏态或极端值明显时，用中位数/IQR补充均值的解释；是否导出额外指标仍由本次交付计划决定。标准差说明样本或总体口径，注意 `ddof`；分位数插值方法也可能影响小样本结果。
- 排名遵循指定指标和方向；标签升序与指标升序不是同一排序。同分使用稳定次序，不擅自扩大用户指定的前 K 项。完整结果与分页预览分开。

## 时间与比较

先解析真实时间、排序，再按用户要求的日/周/月粒度聚合。相同时间有多条记录时先确认度量的可加性；不要把原始行顺序当时间顺序。缺失日期不自动视为零，部分周期与完整周期比较时标明覆盖范围。

相对变化为 `(本期 - 基期) / 基期`；基期为零时不生成无穷数，也不伪造百分比，可报告绝对差和“相对变化未定义”。比例差的百分点与相对百分比要区分。增长、周期变化和局部波动分别描述；少量点不足以证实季节性，更不能自动推广到未来。

## 推断边界

相关分析需要报告实际成对有效样本数和缺失排除规则，相关性不能证明因果。假设检验先明确独立/配对设计、总体、假设和前提，按已安装依赖选择方法；报告效应大小及不确定性。p 值不是假设为真的概率；多重比较需校正或披露探索性，不将普通数值差异称为显著。小样本和观察性数据的结论保留限制。

成果保留原始计算精度，只在报告中格式化。断言应联系原始输入和独立数值关系；自己生成的断言不等于宿主独立核验。
