# 数据可视化

图应回答一个具体问题。类别比较/排名通常选柱状图，时间变化选折线图，数值分布选直方图，两个数值的关系选散点图；矩阵关系可用热力图。选择由实际任务决定，不因为技能提供图型就添加用户未要求的分析。每任务至多两张图，纯表格或明确不绘图时无需绘图。

## 数据与视觉编码

1. 从完整授权快照计算需要的筛选、汇总和转换，保存清楚命名的绘图 DataFrame。图和结果表使用相同口径；不要用前几行、Top K、分页预览替代总体分布。
2. 时间轴先转换为日期/数值并排序。重复横轴先按指标语义聚合；缺失期间是否补零遵从数据含义。分组柱状图保留组与指标的对应关系，不能为了排版改变用户指定的结果次序。
3. 用坐标名称、单位、范围和图例说明图中量。柱状图通常从零基线起；折线图若缩窄纵轴，仍清楚显示刻度，不夸大变化。多个面板比较相同指标时注意统一尺度。
4. 颜色用于区别数据，避免仅靠红绿；可组合线型、标记或直接标签。标签过长时换行或使用横向柱状图，减少重叠；标题必须与真实结果相符，未经计算不把“提升”“显著”写入标题。

## 适配本项目

使用已安装的 Matplotlib，通过 `from helper import load_dataset, emit_figure` 使用辅助接口。导入 helper 会设置已安装的中文字体及无界面后端，不额外下载字体，不覆盖为不存在的本机字体。不要为上游示例中的 seaborn、plotly 或可选包临时联网安装依赖；必要图型可用现有 Matplotlib API实现。

创建 `fig, ax = plt.subplots()` 后完成标题、轴、布局，再调用 `emit_figure(fig, 绘图DataFrame, 授权交付ID, 中文名称)`，由宿主生成 PNG/SVG及关联数据。不要以 `plt.show()`、日志中的文件名、手写图片链接或单独保存到自选路径代替正式交付。数据表列名必须是唯一字符串。

图表提交前核对类别数量、数据点数量、排序和筛选范围；截断展示时写明范围。报告解释引用实际图表与数据，描述总体趋势同时承认局部起伏。图像格式和哈希通过不代表视觉编码已被自动证明正确。
